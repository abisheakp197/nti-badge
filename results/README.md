# NTI Benchmark Results


Signed benchmark reports live here. Each report is Dilithium5-signed and verifiable offline.


## How To Verify


    nti-benchmark verify ./results/benchmark-2026-01-15T10-00-00.json


## What These Prove


Every report binds:
- Framework names + versions
- Attack counts
- Bare scores (without NTI)
- Hardened scores (with NTI)
- Per-attack results


Nobody can forge these results. The signature breaks on tamper.
