# Security Policy

## Reporting a Vulnerability

The NTI team takes the security of `nti-badge` and the NTI trust chain seriously. If you discover a security vulnerability in this repository or live service, please disclose it responsibly.

### How to Report

Do **NOT** open a public issue or discussion for security vulnerabilities.

Please report security issues directly via email to:

**`security@nti-standard.org`** or **`security@bits-ai.org`**

In your report, please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept payload to reproduce the issue.
- Any suggested remediations or patches if available.

### Disclosure Policy

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide an estimated timeline for remediation.
- We request that you maintain confidentiality until a fix has been released.

Thank you for helping keep the NTI ecosystem secure!
